# Local brand assets

- `tokens/{btc,eth,sol,doge,bnb,xrp,ada,link,xlm,zec,avax}.svg`: original color SVGs from [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons/tree/master/svg/color). License: **CC0-1.0**, full text in [tokens/LICENSE.md](tokens/LICENSE.md). Symbols absent from that collection use an initial-circle fallback; USDso is never represented by a different stablecoin logo.
- `somnia-logomark.svg`: unmodified white logomark from Somnia's [official branding kit](https://somniachain.notion.site/Branding-Assets-Somnia-The-Agentic-L1-327b7df18a6b80b19c65dc0167693e24?source=copy_link), linked by somnia.network. Preserve original proportions and fill. Official brand asset, not part of the token icons' CC0 license.

The current Somnia brandbook specifies purple `#771be8`, dark `#070707`, neutrals `#111111`, `#252525`, `#4c4c4c`, `#e6e6e6` and off-white `#f5f5f5`. LucidKeeper's `#bc93f3` is a derived, readable violet text tint, not another official brand swatch. Trading green/red and warning amber are semantic UI colors.
